# KỊCH BẢN BÀI GIẢNG — TIN 6, BÀI 11: ĐỊNH DẠNG VĂN BẢN (2 tiết)

## TIẾT 1
1. **Khởi động (5')**
   - Đọc hội thoại; HS chọn lợi ích của làm sổ trên máy tính.
   - So sánh văn bản A và B → dẫn vào định dạng văn bản.
2. **Phần mềm soạn thảo văn bản (10')**
   - Hoạt động 1: chọn phần mềm (Microsoft Word), nêu chức năng.
   - Câu hỏi SGK tr.48.
   - Trò chơi phân loại chức năng cơ bản / nâng cao.
3. **Định dạng đoạn (12')**
   - Hình 5.4, 5.5; bốn kiểu căn lề; câu hỏi.
   - Ghép lệnh với tác dụng.
4. **Định dạng trang (10')**
   - Page Layout → Page Setup: Orientation, Margins, Size; nhận xét Hình 5.6.
5. **In văn bản (8')**
   - File → Print (Hình 5.7), xem trước khi in, điều kiện để in.

## TIẾT 2
6. **Thực hành trên Word (22')**
   - Sắp xếp công việc.
   - HS soạn bài viết cảm nghĩ theo Hình 5.8: chèn ảnh, căn giữa, căn thẳng hai lề, trang đứng, lề Normal, xem trang in, lưu CamNghiVeBan.docx.
   - Trả lời câu hỏi kiểm tra thao tác; nhóm tick phiếu tự kiểm tra, gửi GV.
7. **Luyện tập (15')**
   - Phiếu học tập: Câu 1 (A); Câu 3 (S, Đ, Đ, S); Câu 2 điền từ (ngang, lề dưới, lề trang).
   - Chọn hướng trang cho 4 văn bản.
   - Bài thơ lục bát (căn giữa); đơn xin nghỉ học; tình huống công cụ gợi ý chính tả sai ngữ cảnh.
8. **Vận dụng (5' + ở nhà)**
   - Nhóm lên kế hoạch thêm trang cho sổ lưu niệm, gửi GV; hoàn thiện trên Word.
9. **Tổng kết (3')**
   - 2 thử thách.
