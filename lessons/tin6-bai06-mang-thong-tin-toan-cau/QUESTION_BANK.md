## Ghép đôi / lật thẻ / kéo–thả / sắp xếp / điền khuyết (không tính vào bảng câu hỏi)
- **Ghép khái niệm ↔ ý nghĩa:** siêu văn bản → tích hợp DL + liên kết · trang web → siêu văn bản có địa chỉ · website → tập hợp trang web liên quan · trang chủ → trang mở đầu tiên · WWW → mạng toàn cầu liên kết các website.
- **Lật thẻ thuật ngữ:** WWW, Website, Trang chủ, Siêu liên kết, Trình duyệt (mặt trước hỏi – mặt sau đáp).
- **Kéo–thả "Đâu là trình duyệt":** Là trình duyệt = Chrome, Firefox, Cốc Cốc, Edge · Không phải = Word (soạn thảo), Wikipedia (một website).
- **Sắp xếp bước truy cập:** nháy đúp trình duyệt → nhập địa chỉ → nhấn Enter → trang hiện ra, theo liên kết.
- **Điền khuyết:** trang mở đầu tiên = **trang chủ**; phần mềm truy cập web = **trình duyệt**; tập hợp trang web liên quan = **website**; chuyển sang trang khác bằng cách nháy vào **liên kết**.

## Ghép cột A ↔ B (Luyện tập SGK)
1) Website là tập hợp → **c)** các trang web liên quan, truy cập qua một địa chỉ · 2) Muốn chuyển sang trang khác, nháy vào → **d)** liên kết trỏ đến đó · 3) Để truy cập các trang web ta cần → **a)** sử dụng trình duyệt web · 4) WWW là hệ thống các → **b)** website trên Internet. **(1-c, 2-d, 3-a, 4-b)**

## Vận dụng (HĐ4)
1. **Sách vs Internet:** Sách tổ chức **tuyến tính** (chủ đề → bài → phần, tìm theo thứ tự trang). Internet **phi tuyến tính** (siêu văn bản + liên kết, nhảy ngay đến trang liên quan).
2. **Khai thác web (hoahoctro.tienphong.vn, vtv7.vtv.vn):** đọc tên & biểu tượng, xem các mục chính (menu), nháy liên kết sang trang khác, bấm ⭐ Bookmark để lưu địa chỉ; lần sau nháy tên trên thanh đánh dấu để mở lại.
