## 4. Bảng điều khiển
| Phím | Tác dụng |
|---|---|
| `→` / `Space` | Màn tiếp theo |
| `←` | Quay lại |
| `Enter` | Xác nhận / lộ đáp án |
| `1 2 3 4` | Chọn đáp án A/B/C/D |
| `F` / `Esc` | Bật / thoát toàn màn hình |
| `T` | Bật/tắt **Chế độ giáo viên** |

**Chế độ giáo viên** cho phép: nhảy tới hoạt động bất kỳ, hiện/ẩn đáp án, reset
điểm/hoạt động, bỏ qua câu, bật/tắt đếm giờ & âm thanh.

- Máy chiếu lỗi màu/chữ nhỏ: dùng `F` toàn màn hình; app đã dùng chữ lớn.
